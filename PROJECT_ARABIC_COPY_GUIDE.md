## Writing Rules

### 1. Short Labels for UI
- Use concise Arabic for buttons and cards
- Example: Instead of "توصيات استراتيجية العروض" use "توصيات العروض"
- Example: Instead of "مراجعة حارس العلامة" use "مراجعة الهوية"

### 2. Professional Business Arabic
- Use formal, professional Arabic suitable for SaaS dashboards
- Avoid literal translations that sound awkward
- Use natural Arabic expressions common in business contexts

### 3. Consistency
- The same concept must use the same Arabic term everywhere
- Refer to this guide when adding new translations
- Update this guide when adding new standard terms

### 4. Avoid Mixing Languages
- Keep Arabic pure except for proper nouns and technical brand names
- Don't mix Arabic and English in the same phrase unless necessary
- Technical terms like "API" can remain in English when widely recognized

### 5. Gender & Number
- Use masculine singular as default for UI elements
- Use plural when referring to collections (Campaigns = الحملات)
- Be consistent with grammatical gender across similar terms

## Common Phrases

### Success Messages
- "Saved successfully" = تم الحفظ بنجاح
- "Updated successfully" = تم التحديث بنجاح
- "Deleted successfully" = تم الحذف بنجاح
- "Created successfully" = تم الإنشاء بنجاح

### Error Messages
- "An error occurred" = حدث خطأ
- "Please try again" = يرجى المحاولة مرة أخرى
- "Required field" = حقل مطلوب
- "Invalid input" = إدخال غير صالح

### Loading States
- "Loading..." = جاري التحميل...
- "Processing..." = جاري المعالجة...
- "Saving..." = جاري الحفظ...

### Empty States
- "No data available" = لا توجد بيانات
- "No campaigns found" = لم يتم العثور على حملات
- "Create your first campaign" = أنشئ حملتك الأولى
